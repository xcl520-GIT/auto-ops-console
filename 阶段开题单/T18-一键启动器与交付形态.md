## 0. ★★★ S0 侦察照出来的四件事（本话题为什么必须做）

### 0.1 ★★★ 起点基线**不是全绿**：`离线 737/738 · 完整 820/821`，唯一的红是 `㊿b`

- 打架的那一处 = **`repo\README.md` L27 停在 `737/737 · 820/820`**，而根 `README.md` / `CHANGELOG.md` / `工程方法.md` 都已经是 `738/738 · 821/821`。
- 来龙：补记② 的提交 `d6e59ce` 给 `selftest.py` 新增了 Ⓢ 那条断言（两条门各 +1），改了 3 份文档的数字，**漏了 `repo\README.md`**；
  而那次跑门发生在**改文档之前**（当时 4 份都还是 737/820 ⇒ `㊿b` 绿）⇒ **改完之后没人再跑门**。
- ⇒ ★★ **T17 交接里那句「738/738 · 821/821（失败 0 · 跳过 0）」，在写下它的那一刻就已经不成立了。**
- ★★★ **这条洞的形状**：**「跑对了」和「记录对了」是两件事**；收口的最后一步是**手写数字**，而**手写数字没有任何判据看住它回到门里**。
  ★ `㊿b` 只查「文档**之间**一致」⇒「4 份一起停在旧数字」它抓不到、「3 份新 1 份旧」它抓得住 —— **这次正是后者，所以它立了功。**
  ⇒ 落成纪律：**改完交付物必须再跑一次门，并把**那一次**的原始输出当证据**（T15「报告里每一句结论都要能被点回它出生的那一次执行」在**门禁数字**上的落点）。
- 证据：`repo\var\artifacts\_manual-对照证据\T18-S0-侦察\T18-S0-05/06/07/08`。

### 0.2 ★★★ 交付物**不可复现构建**，而判据里还写着「逐字节」

| 项 | 值 |
|---|---|
| 源码 `工具\launcher\AutoOpsConsole.cs` | 19054 B · mtime 2026-09-27 20:44:04 |
| 产物 `工具\AutoOpsConsole.exe` | 16896 B · mtime 20:44:11 · sha256 `7697EB32…` |

| **同一份源码再编一次**（第 2 次） | `6CEF87D5…` |

⇒ 本机自带 `csc`（`v4.8.9221.0`）**默认非确定性构建** ⇒ **「磁盘上这个 exe 就是这份 `.cs` 编出来的」用哈希证明不了**。
⇒ ★★ 本项目那条「还原 / 比对一律逐字节」的纪律**在这件事上做不到** ⇒ 判据**诚实降级**为

⇒ ★ 且**没有 build 脚本** ⇒ 编译参数只写在 `.cs` 头注释与说明文档里 ⇒ 属 T17 那个「**信息在，但没送到读它的那一方**」家族。
证据：`T18-S0-03`。

### 0.3 ★★ 「自动找解释器」实际是**一条硬编码的机器专属路径**在兜底

`FindPython()` 四个候补逐个实测：① `AOC_PYTHON`（**未设**）② PATH 上的 `python`（= `WindowsApps\python.exe`，**Length=0 ＋ ReparsePoint**，是**微软商店的执行别名占位**；商店侧只装了 `PythonManager`，**不是解释器**）③ `D:\Python311\python.exe`（**Python 3.11.9** ⇒ **实际就是靠这一条起的**）④ `%LOCALAPPDATA%\Programs\Python`（**不存在**）。
- ⇒ **「自动找解释器」目前实际是「靠硬编码的机器专属路径兜底」**，换机器 / 换目录就找不到 ⇒ **必须如实写进文档**，不许继续说成"通用"。
- ⇒ ★★ **环境与设计约束不一致**：总纲关键约束写 **「后端 Python 3.12 标准库优先」**，实测是 **3.11.9**（T1~T17 全在 3.11.9 上验证）⇒ 要么改文档、要么写明。
- ★ 未做（如实记）：**没有真去执行那个商店别名**（可能弹"安装 Python"引导窗）。用「`where python` 只指向 Length=0 的重解析点」**已经够判**，且符合「**判据不许伤到环境**」。
证据：`T18-S0-04`。

### 0.4 ★★ 启动器**今天无法被自动化断言**（端口写死）

`private const int Port = 8787;` ＋ `const string Url = "…127.0.0.1:8787/"` —— **写死**。
⇒ 任何"占住端口再测认不认人"的判据都会**动到真的 8787**（你正在用的那个控制台）⇒ 撞 T17 §一.4 #4「判据不许伤到环境」。
⇒ ★★ **本话题最硬的设计前置：端口 / 日志目录 / 项目根都必须可注入**，否则下文 11 条验收里的「可证伪」全部无从谈起。

★ 顺带静态读到一处「**同一个开口两处实现不一致**」（第 3 次现场）：

| 入口 | 认不认人 |
|---|---|
| `Start()` | ✅ 三级：在跑＋认 `ping` ⇒ 幂等；认 `health`（401 也算）⇒ 换掉它；**两个都不认 ⇒ 拒绝动手并留窗口** |
| **`Stop()` / `restart`** | ❌ **不认人**：`netstat` 找占着 8787 的 PID ⇒ 全部 `taskkill /F` |

⇒ `restart` = `Stop()` + `Start()`，而 `Stop()` 不做认人判定 ⇒ **`start` 会拒绝的那个"别的程序"，`restart` 会把它杀掉。**
★ **先取数再下结论**：这条要等**端口可注入之后真跑一次**才定级（现在只是静态读出来的差异）。

### 0.5 ★★ 「证据」是**有意**不进版本控制的 —— 所以「可交付」的定义只能是「可复算」

- `repo\.gitignore:20` 就是 `var/artifacts/`，**整体忽略**，而且**注释里写明了理由**：
  「运行期产物不进 Git；**要留证的日志照样会被复制进** `var/artifacts/_manual-对照证据/`（那个目录整体已忽略）」。
- 实测规模：**38364 个文件 / 81.8 MB**（T1~T18 累积）。
- ⇒ ★★ **结论（它形塑了本话题全部判据）**：
  **「交付」不是"我把证据发给你"，而是"别人拿到仓库，能自己把那个结论重新跑出来"。**
  ⇒ 本话题每一条验收都要多问一句：**这条结论，别人用仓库里的东西能不能复算？**
  不能复算的，只算"我说过"，**不算"交付"**。
- ★ 反面现场就是 §0.1：补记② 记的「738/738 全绿」**既不在仓库里、也无法复算**
  ⇒ **一条不可复算的结论，一周之后自己就烂掉了**（而且没人知道，直到有人再跑一次门）。

## 1. 目标（一句话）

**把「启动这个控制台」从「记三条命令 / 猜它起没起来 / 不知道跑的是哪一版」变成「双击一下，并且它给你一句能被独立复算的结论」；
顺手把「交付形态」这件事本身做成可审计的（谁建的快捷方式、在哪儿、怎么撤、编译参数在哪、源码与产物怎么对上）。**

★ 一句话版本：**让"它到底起没起来"从一个"感觉"变成一条"结论"。**

## 2. 范围（做什么）

### 2.1 主线一 · 把启动器**纳入可证伪面**（★ 本话题的技术核心）

- 现状：启动器**跑在 `repo\` 之外**，两道门**扫不到它**，它的六件事全是"人肉试过"。
- 做法：**参数可注入**（`AOC_PORT` / `--port` ＋ 日志目录 ＋ `AOC_ROOT`）⇒ 断言可以在**临时端口 ＋ 临时目录**里跑**启动器真身**，
  ★ **不碰真的 8787**（「判据不许伤到环境」）。
- 落点：`repo\tools\` 新增断言（★ 允许改 `repo\tools\**`；见 §3）＋ `工具\` 侧一个可被 `import` 的判定函数（学补记② 那条 Ⓢ 的做法：**不查字符串，把判定函数 import 进来真跑**）。

### 2.2 主线二 · 六种情形各有「一句话结论」，且能被脚本读

| # | 情形 | 期望的结论 | 脚本可读 |
|---|---|---|---|
| ① | 没在跑 | 「没在运行」＋ 双击就起来 | 退出码 / `--json` |
| ② | 已经在跑 | **幂等**：不重复起，只开浏览器 | 同上 |
| ③ | 8787 被**本控制台的旧版本**占着 | 「跑的是旧版本」⇒ 换掉 | 同上 |
| ④ | 8787 被**别的程序**占着 | **拒绝动手**，说清"不是我们的"，**不杀** | 同上 |
| ⑤ | 找不到解释器 | 说清试过哪些位置（**不许只说"失败"**） | 同上 |
| ⑥ | 口令还没设过 | 如实报「口令：还没设过 —— 界面会先让你设」 | 同上 |

★ ③④⑤ 三条都要有**反例真跑**（占位监听器 / PATH 上只放别名 / 把候选全指空）。

### 2.3 主线三 · **版本一致性**：把「跑的是旧代码」这条路堵上

- 能力**已经在**：`/api/auth/ping`（免鉴权）已返回 `version / stage / configured`；版本唯一来源 = `repo\app\__init__.py:__version__`。
- 新增：`status` **同时报出**「磁盘上是哪一版」vs「跑着的那个进程是哪一版」，不一致就**明说**（T13 踩过：跑的是旧进程，`/api/ai/**` 当时根本不存在）。

### 2.4 主线四 · **交付形态**：桌面快捷方式 ＋ 开始菜单项（★ 可建 / 可撤 / 可审计）

- 建：在 `%USERPROFILE%\Desktop` 与 `%APPDATA%\Microsoft\Windows\Start Menu\Programs` 各建一个指向 `工具\AutoOpsConsole.exe` 的 `.lnk`。
- ★ **可撤**：一键撤销自己建的（**只删自己建的那两个**，别的不动）；
- ★ **可审计**：把「我建了什么 / 建在哪 / 指向什么」**打出来**并落证据（T7 口径「**回不去的要逐项说清**」）。
- ★ 界面**不在**本话题范围内：这是 `repo\` **之外**的交付形态（见 §3 第 2 条）。

### 2.5 主线五 · 交付物自身的「可交付」：构建脚本 ＋ 数字纪律

- `工具\build-launcher.cmd`：把编译参数从注释里搬进脚本（**一条命令重建**），并把**源码 sha256 与产物 sha256**都打出来。
- ★ 两条门的数字，在**最后一次改动之后**重跑并把**那一次**的原始输出留证（§0.1 的纪律）。
- 顺手还债：`repo\README.md` 那 1 条漂移 ⇒ 起点基线回到**真全绿**（`738/738 · 821/821`）。

## 3. **不做什么**（划清边界，防范围失控）

1. ❌ **不用 PyInstaller / 任何打包器**把整个应用做成单文件 exe（路线图 §3.1 已定：要处理 `sys._MEIPASS` / SQLite / ssh 子进程，
   体积几十 MB，且**必须改平台代码找路径的方式** ⇒ 撞「平台代码零改动」）
2. ❌ **`repo\app\**` 与 `repo\web\**` 一行不改**（承重墙）。★ **允许改的只有** `repo\tools\**`（自检）＋ `工具\**`（交付形态）。
   ⇒ ★ 这条本身就写进验收（用 `proof_add_action.py` 同族的方式**证明**它）
3. ❌ **不装任何东西**：仍用系统自带 `csc`；不装 .NET SDK、不装 Python 依赖
4. ❌ **不做开机自启**、**不做托盘图标**、**不做 Windows 服务化 / 后台常驻**（★ 拍板 2）
5. ❌ **不代填任何凭据**：模型 key 不落盘（红线 8）、控制台口令（红线 11）—— 启动器**根本不管口令**
6. ❌ **不杀别人的进程**：8787 被非本控制台程序占着 ⇒ **只报告**（★ 但 §0.4 那条 `restart` 的差异要**查清并如实处置**）
7. ❌ **不改绑定地址**：控制台必须仍绑 `127.0.0.1`（红线 3）；启动器**不许**为了"方便"改成 `0.0.0.0`
8. ❌ **不做自动更新 / 不在启动器里 `git pull`**
9. ❌ **不给 AI 开后门**：AI 仍**只走 `/api/**`**（铁律 8 / 9）；本话题**不新增任何 AI 工具**
10. ❌ **不替代 T17 遗留 #4/#5 的「改地址」小配方**（本次拍板是 A；那条顺延，见 §11）
11. ❌ **不做多用户 / 不做远端部署**（仍是本机工作台）

## 9. 技术要点与坑（★ 预判，S0~S8 逐条验）

### 9.1 带进来的口径（T17 §一.4 / §一.5，逐条找落点，不许只写在规范里）

1. **能证伪才算判据**（注入必须**真红**，还原后**真回绿**）
2. **判据不许伤到环境**（★ 本话题的**头号约束**：临时端口、临时目录）
3. **「问不到」与「不存在」要分开报**（★ 启动器"找不到解释器"必须**列出试过哪些位置**）
4. **默认值是给界面看的，不是给脚本看的**（★ 端口 / 路径的默认值也一样）
5. **归因不许想当然 —— 先取数，再下结论**（§0.4 那条差异**必须先真跑**才定级）
6. **"做不到"要写在明面上**（★ 不可复现构建就是这一条）
7. **同一个开口，两处实现都要认账**（★ `start` vs `stop/restart`）
8. **"命令返回 0" ≠ "事情成了"**；9. **"读不到" ≠ "没成功"**；
10. **中文串里一律用「」**；改完**立刻编译**；11. **别用 `Select-Object -First` 截流**；
12. **判据不能判自己**（源码扫描走 AST）；13. **"给人看的那段话"必须有断言**；
14. **每完成一个 S 步就跑 `git add -A && git commit`**（别指望"我记得"）

### 9.2 本话题专有的坑（预判）

1. ★★ **不要为了"能测"而把控制台停下来测** —— 那会打断你正在用的东西。**端口可注入**是正解（§0.4）。
2. ★★ **`.lnk` 是二进制文件，不能"逐字节比对"** —— 判据只能落在**可解析的字段**上（目标路径 / 参数 / 工作目录 / 图标），
   或者**建完读回来比对**（用 WScript.Shell 读 `.lnk` 的 TargetPath）。★ 这是"逐字节做不到"的**第二处**。
3. ★ **老 `csc` 是 C# 5 语法**（`out string why` 这种 C# 7 写法会报 `CS1513 / CS1520`）—— 已在说明文档里留档，别踩第二次。
4. ★ **`taskkill` 的中文输出要走 OEM 代码页**（源码里 `Cli()` 已经处理）—— 改这块别把它弄丢。
5. ★ **环境变量要先设再起子进程**（`psi.EnvironmentVariables["PYTHONIOENCODING"]="utf-8"` 已有）——
   端口注入也走同一条路（`AOC_PORT`），**不要**改成命令行参数传给 `app.server`（那是改平台代码）。
6. ★★ **`app\server.py` 可能根本不读 `AOC_PORT`** —— 若"端口可注入"要动 `repo\app\**`，就撞 §3 第 2 条。
   ⇒ ★ **先取数**：`repo\app\server.py` / `config.py` 里端口是从哪来的；**若只能改平台代码才能注入，就必须回来问用户改边界**（不许自己放宽）。
7. ★ **桌面 / 开始菜单是项目目录之外的写操作** —— 只建**这一个** `.lnk`，别的一律不碰；撤销必须**只删自己建的那两个**。
8. ★ **`restart` 的 1 秒 `Thread.Sleep(1000)`** 是脆的（端口 TIME_WAIT / 旧进程没退干净）⇒ 要等**真释放**（学 `Stop()` 里的轮询）。
9. ★ **非确定性构建 ⇒ 别把"重编后 hash 变了"当成"文件被改了"** —— 反过来说：**别用 hash 判断 exe 有没有被换过**。
