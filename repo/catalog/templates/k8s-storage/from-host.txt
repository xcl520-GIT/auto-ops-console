# ============================================================
# 模板：宿主机预先写进卷里的那一份（T8 · S7）
# ------------------------------------------------------------
# ★ 两个用途（都要）：
#   ① **建目录**：模板写入自带 `mkdir -p`（规范 §12.13.6）——
#      `local` 卷的 `path` 必须先存在，否则 PV 永远绑不上；
#   ② **当"读"的那一端**：Job 会把它读出来并留一张 receipt，
#      平台再在宿主机上读 receipt ⇒ **两个方向都留了证**。
#
# ★ 内容里带上 `{{ pv_name }}` 与 `{{ storage_path }}`：
#   那些是**渲染后的真值**，一眼能对上是哪条卷、哪个目录（规范 §12.6 清单 37 同族）。
# ============================================================
from-host.txt (T8·S7 存储类验证)
pv={{ pv_name }}
path={{ storage_path }}
node={{ storage_node }}
host-side-content=aoc-storage-ok

如果你（Pod 里的那个容器）读到了这几行，说明这个卷**真的**被挂上了；
把它原样写成 /data/pod-receipt.txt，平台会在宿主机上核对。
