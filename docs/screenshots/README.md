## 怎么自己复现（一条命令）

```powershell
cd repo
python -m app.server                        # 起控制台（另开一个窗口）
cd ..
$env:AOC_CONSOLE_PASSWORD = "你的控制台口令"  # ★ 口令只走环境变量：不写进脚本、不落盘
python 工具\capture-screenshots.py          # 12 个页签逐个走查 + 按钮级真点一次（截图 + 文字快照 + 运行时错误）
```

★ 脚本用**独立的浏览器 profile 与调试端口**，不会影响你正在用的浏览器；跑完自动关闭自己启的进程。
★ 复跑出的截图数量与文件名应与下表**一致**（这是交付物对账的一部分）。

★★ **两道前置判据：不满足直接拒绝跑**（★ 本轮真踩过，规范 §12.113）：

1. ★★ **版本对齐** —— 正在跑的控制台进程版本必须**等于磁盘上的版本**。
   ★ 本章第一次走查就是**给一个 T14 的旧进程拍的照**：页首写着 `T14 · v0.12.0`，而磁盘已经是 T15。
   同一张「报告」页签：**旧进程 738 字符 ／ 正确版本 16971 字符** —— 差的那 16000 多字，
   就是**旧进程里根本不存在**的 `/api/ai/reports`。⇒ 不等则**退出码 4**，提示先重启控制台。
   ★ 结论：**"拍了照" ≠ "验过了"**；一叠好看但无效的截图比不拍更糟。
2. ★★ **走查表同序** —— 本脚本的 `TABS` 必须与 `web\index.html` 的 `data-tab` **逐个同序**。
   ★ 它当时**只有 8 个页签、界面已经 11 个** ⇒ **T12 / T14 / T15 新增的三个页签从来没有真人看过**
   （T14 那颗「三个导出入口全部 401」，一半原因就在这儿）。⇒ 不等则**退出码 5**。

★ 两条判据也都在**离线门**里看住：自检断言 **Ⓘ** · 规范 **§12.113** · 检查清单 **237**。

## ★★ 第二段：按钮级走查（**真点一次** · T16 起）

★★ 页签"点得开、读得回"**不等于**界面对。T14 那颗「**三个导出入口全部 401**」的洞，
恰恰是在**所有页签都不报错**的情况下存在的 —— 静态断言全绿、切换全绿，**只有真按下去才现形**。
⇒ 所以 T16 起脚本多走一段（`_button_walk()`）：

| 真点的那一下 | 判据（★ 不是"按钮点下去了"） |
|---|---|
| **导出（.txt）**：历史 → 回放 → 按「导出报告」 | 下载目录里**真的出现文件且字节数 > 0**（「点了 ≠ 成了」） |
| **锁定 → 登录**：按「锁定」→ 输口令 → 按「登录」 | 门**真的亮出来**、令牌**真的被清**；登录后门**真的关上**、拿到新令牌、动作卡片**真的渲染出来** |
| **改口令**：按「改口令」 | 界面契约（标题 / 「当前口令」字段 / 「再输一次」字段 / 首字段标签）—— ★ **只点开、不真改**（真改会吊销所有令牌并改掉你的秘密） |

★ `⏭` 表示**这次没验到**（例如没给 `AOC_CONSOLE_PASSWORD`，登录那一步跳过）—— **跳过不算通过**。
★ 这一段**不能**覆盖：`yellow`/`red` 变更动作（闸门只有一处，不在这里执行）· 跨机跨集群的真实编排 ·
   改口令本身。完整边界见规范 **§12.121.1 / §12.121.2**。
★ 按钮级失败 ⇒ **退出码 6**。
