## 4. ★ 带进 S6~S10 的口径

1. **判据不许伤到环境** —— 本话题的头号约束（临时端口 / 临时目录 / 临时快捷方式落点）。
2. **"跑对了" ≠ "记录对了"**：**改完交付物必须再跑一次两道门，并把那一次的原始输出当证据**。
3. **不可复现构建**：判据 = 大小一致 ＋ 行为等价 ＋ 源码 sha256；**"逐字节做不到"写在明面上**。
4. **结论两用**：人话 ＋ 退出码 / `--json`；★ `--json` 模式**不等按键**（否则脚本挂死）。
5. **认人只有一道口子**：凡"会结束一个进程"的入口都走**同一道**判定；**不提供 `--force`**。
6. **同一个开口，两处实现都要认账**（本话题第 3 次现场）。
7. ★ **`.bat` / `.cmd` 必须纯 ASCII**（连 `rem` 里也不许有非 ASCII）。
8. ★ **改完 `.cs` 必须重跑 `工具\build-launcher.cmd`**（探针 ⓪ 会红）。
9. ★ **中文串一律用「」**（本轮在 PowerShell 与 Python 里**各踩了 5 次**英文引号 —— 写脚本时先想这一条）。
10. ★ **`git commit -F` 的信息文件要用 `UTF8Encoding(false)` 写** ——
    PS 5.1 的 `Out-File -Encoding UTF8` **会写 BOM**，`c8e3a44` 的标题第一个字就带了个 `﻿`。
11. ★ **探针自己也会说谎**：判据"绿"要能证明它**验到了东西**（方法：证伪 ＋ 夹具必须落在**真会被读到的那一格**）。
