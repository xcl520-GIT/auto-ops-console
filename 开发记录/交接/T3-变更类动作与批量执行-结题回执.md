## 5. 踩过的坑（★ 下次别踩）

> 本话题的坑分两类：**环境坑**（换机器带来的）与**平台坑**（写代码/写 YAML 时撞出来的）。
> 后一类里 #2~#4 已经写进规范 §9.6~9.8 —— 它们不是"注意一点就好"，而是**校验也拦不住的**那种。

| # | 坑 | 症状 | 怎么绕 |
|---|---|---|---|
| **0** | **"冷启动"被当成用户该干的活** | 用户原话："以后为了用你这个平台工具，还要自己去改公钥，不是本末倒置吗" | 这是**产品设计问题**，不是操作问题。短期用"一条不含密钥的固定命令"（HTTP 分发点）；长期做 `host.enroll`（已列 T4） |
| **1** | **同名不同把的公钥** | 用户贴了命令、指纹却是 `csiHaFIy…`（我们的私钥配的是 `qJoghe9Y…`）；两把都合法、注释都叫 lobehub-ops | 别让用户手抄密钥：用 `ssh-keygen -lf` **比指纹**，或直接让机器传（管道/scp） |
| **2** | **YAML 标量里的 `: ` 必须加引号**（本话题踩了**两次**） | `help: … @ . _ : -` → `mapping values are not allowed here`；`status: 动作声明 backup: 段` 同样报错 | 含 `: ` 的值一律**单引号**；中文文案优先用全角「：」（不触发）。规范 §9.7 |
| **3** | **`run` 元素含逗号必须加引号**（最隐蔽） | `-o NAME,KNAME,TYPE` 被 YAML 流式数组按逗号拆成 3 个元素 → 远端收到 `lsblk -o NAME KNAME TYPE` → **rc=32 + 一个合法的空设备树** `{"blockdevices": []}`，看起来像"这台机器没有磁盘" | 含 `,` 的 `run` 元素加双引号。**加载校验抓不到**（拆开后每个元素都合法），只能靠真跑 + 看留证里的**命令原文**。规范 §9.8 |
| **4** | **"某物不存在"不能写成 verify 的非空断言** | `cron.remove` 的自证"确认文件已不存在"取自 `ls` 输出，而不存在的文件**没有 stdout** → 每次都报假失败 | 由**退出码**承担（`ls` 只接受 2 / `rpm -q` 只接受 1 / `is-active` 只接受 3 / `--query-port` 只接受 1），另外找一个"确实有输出"的事实兜底。规范 §9.6 |
| **5** | **动作层没有"写文件/传文件"能力** | `cron.upsert` 要写 `/etc/cron.d/*`，而 `run` 禁重定向；`file.push` 要上传，而引擎只能跑远端命令 | 新增两种"非 run"步骤 `write_file` / `transfer`（平台能力，一次性投入）。规范 §9.5 |
| **6** | **备份阶段的未预期异常会炸掉整个流程** | `_backup_one` 里一个 `NameError` 直接把整个动作抛出，而不是"备份失败 → 中止" | 备份阶段**任何**异常都降级成 `BACKUP_FAILED` + 中止动作（宁可不动，也不能"备份状态未知"就动手） |
| **7** | **横向对比不能拿结论文本比** | 4 台明明语义一致，却因为结论里含各自的 PID/时间戳被判成"4 组差异" | 按「**任务状态 + 自证结果**」分组；结论里的天然差异值不参与比对 |
| **8** | **设备掉线时工具调用会"静默失败/假成功"** | 掉线瞬间发出的 `editFile` 报"Successfully replaced"，复核发现**根本没落盘** | 掉线恢复后**第一件事是复核**那几个未见结果的操作；（T2 坑 #11 的同类现象，本次再犯一次） |
| **9** | **同一文件每批只能发一个编辑** | 一次发 3 个 `editFile` 到同一文件，第 2 个必然报"old_string not found" | 同一文件一次只发一个编辑；不同文件可并行 |
| **10** | **`.NET` 的 `[IO.File]::ReadAllBytes` 用进程工作目录**，不是 PowerShell 的 `cd` | 传相对路径 → `DirectoryNotFoundException`，导致靶子恢复脚本静默没执行 | 用绝对路径（这类"看起来执行了"的静默失败最费时间） |
| **11** | **代码里的中文全角/半角引号混用会毁掉 Python 字符串** | `note` 里写了 `"语义一致"`（ASCII 双引号）→ `SyntaxError`，且报错指向上一行 | 字符串里用「」或全角引号；改完立刻 `py_compile` |
