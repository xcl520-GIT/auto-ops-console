## 5. 踩过的坑（★ 下次别踩）

> 本节是本次会话最有价值的部分。**6 个真 bug 里有 4 个属于"命令退出码 0、程序不报错、结论却是错的"** ——
> 全部是被 `verify` 自证机制和"界面结果 vs 手工输出逐字对照"逼出来的。
> 这条经验直接支撑了开题单「每个动作必须写 verify，不许执行完就假定成功」。

| # | 坑 | 症状 | 怎么绕 |
|---|---|---|---|
| 1 | **远端 locale 导致字段名本地化 → 静默取空** | 目标机 `LANG=zh_CN.UTF-8` 时 `timedatectl` 输出「本地时间」而非 `Local time`；按英文字段名解析 → 空字典、退出码 0、界面显示"成功"、结论全是（无） | 所有远端命令加 `env LC_ALL=C LANG=C` 前缀（`config.yaml` 的 `ssh.remote_env`）。**用 `env` 而非 shell 变量前缀**，同时避开"拼接"这件事 |
| 2 | **引擎忘了把解析结果写回 `ctx`** | 所有步骤退出码 0、动作状态 ok，但结论全是（无）、断言全不通过 | 在 `engine.run()` 里执行完步骤后 `ctx[s.name] = out.parsed`。**是 verify 断言把它拦下来的** |
| 3 | **`free -m` 解析器把表头写成了 `parts[1:]`** | `total` 列被吃掉 → 每一列整体**左移一格**：界面显示"已用 3619MB"（其实是总量）、"共（无）MB" | 表头必须包含 `parts[0]` 本身 |
| 4 | **同一个解析器把标签 `.lower()` 了** | 产出 key 是 `mem`，而动作 YAML 引用 `{mem.Mem.total}` → 全取不到 | 保留原始大小写（`Mem` / `Swap`），只去掉行尾冒号 |
| 5 | **"退出码非 0 就不解析输出"** | `systemctl is-system-running` 在 `degraded` 时返回 1，而 `degraded` 这个词正是我们要的结论 → 被整个丢掉 | ① 只要 stdout 有内容就**照常解析**；② 新增 `ok_exit_codes` 字段，让动作显式声明"这些退出码是正常报告" |
| 6 | **`format_value` 不认识 foreach 的产出结构** | 失败明细渲染成 `· t1-fixture.service：value={'Result': ...}` | 识别 `{"iter":…, "value":…}` 结构并展开 |
| 7 | **自检里的防注入断言本身写错了** | 用"危险子串是否出现在命令字符串里"判定 → `shlex.quote` **故意把元字符原样留在单引号内**，必然误报 | 唯一可靠判据：把远端命令按 POSIX shell 语义 `shlex.split()` 重拆，断言**能还原成原 argv**，且 token 数精确匹配 |
| 8 | **PowerShell 函数名 `R` 撞内置别名** | `R "命令"` 被解析成 `Invoke-History`，一堆 "找不到命令行的历史记录" | 别用单字母函数名（`R`/`h`/`?` 等都是内置别名） |
| 9 | **Windows 中文控制台 gbk 编码不了 `✅`** | 服务**启动即崩溃**（退出码 1），但只在 `stdout` 被**重定向**时暴露；直接跑控制台反而不触发 | `server.py` 的 `_fix_streams()`：非 tty 时改 utf-8，tty 时仅 `errors="replace"` |
| 10 | **`.vmx` 的 `guestOS` 不代表实际安装的系统** | `guestOS = rhel9-64`，实际装的是 **RHEL 10.0** → 据它下过"这是降级验证机"的错误结论（已当场纠正） | 一律以机器内 `cat /etc/os-release` 为准 |
| 11 | **`systemctl --output=json` 是单行 JSON 数组** | 用 `grep -c unit` 数服务个数会得到 `1`（整份 JSON 只占一行） | 让 `json` 解析器解析后用 `.count` 取长度；**不要**在 shell 里数行 |
| 12 | **`--target` 装依赖后忘了 sys.path** | `tools\_check_yaml.py` 用 `Path(__file__).parent` 得 `tools/`，而文件在 `repo\tools\` → 少退一级 | 工具脚本一律 `parent.parent`，或显式打印解析出的路径 |
| 13 | 读 VMware 虚拟机清单 | 默认路径找不到安装 → 漏判"没装 VMware" | 查注册表 `HKLM:\SOFTWARE\VMware, Inc.\VMware Workstation` 的 `InstallPath`，以及 `%APPDATA%\VMware\inventory.vmls` |
